When you hover over a button, the tooltip (near the button) shows helpful information about it.

For more details, see the table below.


Function Keyboard Shortcut Description
Basic Functions
Add + Performs an addition of two numbers.
Subtract - Performs a subtraction of two numbers.
Multiply * Performs a multiplication of two numbers.
Divide / Performs a division of two numbers.
± s Changes the sign of the number.
Percentage % Calculates percentages. (a × P%=a × P/100)
abs a Returns the absolute value of x.
mod Shift + M Returns the remainder of a division (only with integers).
1/x i Returns the reciprocal of x.
. . Decimal point.
Equals Enter Returns the result of the current operation.
AC Esc Clears the current input.
DEL Backspace Deletes digits one by one.
Memory Functions
M m Adds the current value to memory.
MR Ctrl + M Recalls the value from memory.
MC Alt + M Clears the memory.
Exponential, power and logarithmic Functions
xy ^ Returns x raised to the power y.
x², 10x z Returns x² or 10^x (depending on the mode).
x²→10x, 10x→x² y Switches the power mode (x² ⇄ 10x and log₂(x) ⇄ log₁₀(x)).
n√ n Returns the n-th root of x.
√x Ctrl + S Returns the square root of x.
³√ Ctrl + C Returns the cube root of x.
ex x Computes e to the x-th power. x<710
ln(x) l Returns the natural logarithm of x.
log₂(x), log₁₀(x) Ctrl + L Returns the base-2 or base-10 logarithm of x (depending on the mode).
logab Alt + L Returns the logarithm of b with base a.
e e Returns the value of mathematical constant e.
Trigonometric Functions
sin(x) Alt + S Computes the sine of x.
cos(x) Alt + C Computes the cosine of x.
tan(x) Alt + T Computes the tangent of x.
asin(x) Not Set Computes the arcsine of x (-1≤x≤1).
acos(x) Not Set Computes the arccosine of x (-1≤x≤1).
atan(x) Not Set Computes the arctangent of x.
DEG/RAD r Switch from degrees mode to radians mode and vice versa.
Angle Conversion
°→rad Alt + R Convert degrees to radians. (x=ɑ × π/180)
rad→° Alt + D Convert radians to degrees. (ɑ=x × 180/π)
π Shift+P Returns the value of mathematical constant π.
DMS to Decimal Conversion and vice versa
DEC→DMS g Convert decimal number to DMS format (Degrees, Minutes and Seconds)
DMS→DEC Alt + G Convert DMS formatted number to decimal.
Colons : Colons are used to separate Degrees, Minutes and Seconds.
(Example, 30:15:25.6 is understood as 30°15'25.6")
Factorial, Combinations and Permutations
n! ! The factorial of n. (0≤n≤171, n ∈ N.)
nCr c Computes combinations: nCr = n! / (r!(n-r)!)
nPr p Computes permutations: nPr = n! / (n-r)!
Number System Functions
DEC d Converts a number to decimal (only for integers).
-2147483647 ≤ x ≤ 2147483647
BIN b Converts a number to binary (only for integers).
0 ≤ x ≤ 01111111111111111111111111111111
10000000000000000000000000000000 ≤ x ≤ 11111111111111111111111111111111
OCT o Converts a number to octal (only for integers).
0 ≤ x ≤ 17777777777
20000000000 ≤ x ≤ 37777777777
HEX h Converts a number to hexadecimal (only for integers).
0 ≤ x ≤ 7FFFFFFF
80000000 ≤ x ≤ FFFFFFFF
A,B,C,D,E,F A–F Hexadecimal digits.
A=10, B=11, C=12, D=13, E=14, F=15.
Can be used only for HEX mode.
Bitwise Operators
AND & Bitwise AND (only for integers).
OR | Bitwise OR (only for integers).
XOR $ Bitwise XOR "exclusive or" (only for integers).
NOT ~ Bitwise NOT (only for integers).
NAND Alt + & Bitwise NAND "not-and" (only for integers).
NOR Alt + | Bitwise NOR "not-or" (only for integers).
XNOR Alt + $ Bitwise XNOR "exclusive not-or" (only for integers).
