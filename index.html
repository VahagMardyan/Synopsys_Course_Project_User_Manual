When you hover over a button, the status bar (at the bottom) shows helpful information about that button.
The text format is: function description (keyboard shortcut).

For more details, see the table below.


Function Button on keyboard Description
Basic Functions
Add + Performs an addition of two numbers.
Subtract - Performs a subtraction of two numbers.
Multiply * Performs a multiplication of two numbers.
Divide / Performs a division of two numbers.
± s Sign
Percentage % Returns percents. (a*P%=a*P/100)
abs a The absolute value of an argument.
mod shift + m Returns the remainder of a division (only with integers).
1/x i Returns the reciprocal of x.
. . Dot
Equals to = or Enter Returns the result of the current operation.
AC esc Clears the current input.
DEL delete or backspace Deletes digit by digit.
Memory Functions
M m Add to memory.
MR Ctrl + M Memory Recall
MC Alt + M Memory Clear
Exponential, power and logarithmic Functions
x^y ^ Returns the 'y' power of 'x'.
x², 10^x z Returs the x² or 10^x (depends on mode).
Switch power mode (no special button). y Switch the power mode (x² <=> 10^x or log₂(x) <=> log₁₀(x))
n√ n Returns the n-th root of x.
√x Ctrl + S Returns the square root of x.
³√ Not Set Returns the cube root of x.
exp(x) x Returns the x power of e.
ln(x) l Natural logarithm of x.
log₂(x), log₁₀(x) Ctrl + L Returns the 2-base or 10-base logarithm of x (depends on mode).
log(a,b) Alt + L Returns the a-base logarithm of b.
e e Returns the value of mathematical constant e.
Triganometric Functions
sin(x) Alt + S A triganometric function.
cos(x) Alt + C A triganometric function.
tan(x) Alt + T A triganometric function.
asin(x) Not Set A triganometric function (-1≤x≤1).
acos(x) Not Set A triganometric function (-1≤x≤1).
atan(x) Not Set A triganometric function.
DEG/RAD r Switch from degrees mode to radians mode and vice versa.
°→rad Alt + R Convert from degrees to radians. x=(ɑ*π/180)
rad→° Alt + D Convert from radians to degrees. ɑ=(x*180/π)
π shift+p Returns the value of mathematical constant π.
Sexagesimal Functions
DEC→DMS g Convert decimal number to sexagesimal format (Degrees, Minutes and Seconds)
DMS→DEC Alt + G Convert sexagesimal formatted number to decimal.
Colons : Colons are used to separate Degrees, Minutes and Seconds.
(Example, 30:15:25.6 understands as 30°15'25.6")
Factorial, Combiantons and Permutations
n! ! The factorial of n. (0≤n≤171, n ∈ N.)
nCr c Combination. nCr=n!/(r!(n-r)!); n≥r; 0≤n,r≤171 n,r ∈ N.
nPr p Permutation. nPr=n!/((n-r)!); n≥r; 0≤n,r≤171 ∈ N.
Number System Functions
DEC d Converts number to decimal (only with integers).
-2147483647 ≤ x ≤ 2147483647
BIN b Converts number to binary (only with integers).
0 ≤ x ≤ 01111111111111111111111111111111
10000000000000000000000000000000 ≤ x ≤ 11111111111111111111111111111111
OCT o Converts number to octal (only with integers).
0 ≤ x ≤ 17777777777
20000000000 ≤ x ≤ 37777777777
HEX h Converts number to hexadecimal (only with integers).
0 ≤ x ≤ 7FFFFFFF
80000000 ≤ x ≤ FFFFFFFF
A,B,C,D,E,F A-F Hexadecimal digits. A=10, B=11, C=12, D=13, E=14, F=15
Bitwise Operators
AND & Bitwise AND (only with integers).
OR | Bitwise OR (only with integers).
XOR $ Bitwise XOR "exclusive or" (only with integers).
NOT ~ Bitwise NOT (only with integers).
NAND Not Set Bitwise NAND "not-and" (only with integers).
NOR Not Set Bitwise NOR "not-or" (only with integers).
XNOR Not Set Bitwise XNOR "exclusive not-or" (only with integers).
Other Functions
Focus (No button) Any button on calculator, Tab Focuses on display.
HELP ? or F1 Opens the user-manual.
Quit program (No special button) Alt + Q or Alt + F4 Close the program.
